# Local Money Map use

Updated October 7, 2026. Scope: personal use and a handful of users. [Working approach](../personal-use.md).

Use the existing installed app if it works, or the repository-mode server in [Development](../development.md). Start with one useful account/cash-flow/goal/plan workflow and get feedback. Full expanded feature completion is not needed before that use.

Real financial setup remains a separately authorized action. Use a small synthetic sample while developing; before changing real data, preserve a backup and use supported import/migration services. Each user keeps a separate private data root and credentials.

A new signed DMG, build ID, candidate manifest and installed acceptance campaign are not required for the current local-use path. Preserve the existing installed app and permission/Keychain identity if a needed native update is made. Check launch and the changed behavior.
