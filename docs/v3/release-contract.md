# Personal-use delivery requirements

Updated October 7, 2026. Scope: personal use and a handful of users. [Working approach](../personal-use.md).

Current delivery means a working local server or installed Mac app for the owner and a handful of users. Use [local development](../development.md) and [local app use](owner-local-delivery.md).

Required for an actual update: preserve financial data/credentials, use supported schema/import paths, keep accounting and saved assumptions correct, and check the affected flow. Native app identity matters only when an actual update needs existing platform permissions/Keychain access.

Mandatory clean-commit release builds, signed installer/DMG production, reproducibility inventories, multi-stage package validation, tagging/publishing and formal acceptance worksheets are removed from the current work order. Existing tooling is retained for a future concrete distribution need.
