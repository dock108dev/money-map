# Practical installed-app checks

Updated October 7, 2026. Scope: personal use and a handful of users. [Working approach](../personal-use.md).

Use the current installed app or local server and try the feature being improved. Check open, the changed task and save/reopen. If native lifecycle/input/proxy code changed, check the affected native behavior too.

Before real-data/schema changes, take a backup and preserve prior state. Use a copy for an unfamiliar destructive migration. A full installed-candidate sequence, fixed launch counts, synthetic-to-owner acceptance campaign, package inventory and native fault matrix are not prerequisites to personal feedback.
