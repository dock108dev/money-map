## Product summary and desktop architecture

Money Map packages the accepted React product in one Tauri 2 macOS shell with one bundled
PyInstaller/FastAPI sidecar. The shell owns its native window, menus, authenticated ephemeral
loopback transport, sidecar lifecycle, explicit file selection, and private macOS locations.
SQLite remains the financial-data authority and macOS Keychain remains the optional Plaid secret
authority. No cloud account, hosted database, automated transfer, or financial write service is
added.

Public version surfaces map to `3.0.0-beta.1`. Python package metadata uses the PEP 440 canonical
equivalent `3.0.0b1`. Schema remains exactly `0009_goal_persistence`; migration `0010` does not
exist.

## Data home, migration, backup, restore, and rollback

Production state belongs in private Money Map Application Support, cache, and log locations. The
app never scans for legacy data. The owner explicitly selects a source; inspection remains
read-only. Cutover creates and verifies an online SQLite backup, migrates only isolated staging
through `0009`, compares complete logical manifests, verifies integrity and foreign keys, and
atomically activates only a verified candidate. The original is retained.

Replacement creates a verified safety backup and preserves a rollback pointer. An interrupted
operation resumes only a verified staging copy or offers rollback through the digest-verified
journal. Restore re-verifies the selected backup, creates a pre-restore safety backup, stages the
replacement, and retains the last accepted database until verification completes.

## Local security, Keychain, and Plaid boundaries

The native shell supplies a per-launch 256-bit session over a private inherited descriptor. The
sidecar binds only an OS-selected `127.0.0.1` port and rejects untrusted sessions, origins, hosts,
methods, paths, sizes, and response framing. Diagnostics and evidence are allowlisted and
sanitized. Private data, credentials, sessions, raw identifiers, and owner paths are forbidden
from the app bundle, DMG, logs, crash output, screenshots, and evidence.

Plaid remains optional and read-only. Production credentials and access tokens remain in exact
macOS Keychain namespaces and are never build inputs. Slice 8 performs no provider or production
Keychain operation. Manual file import remains a permanent first-class fallback even when Plaid is
configured.

## Bounded owner-beta plan and rollback instructions

Follow `v3.0.0-beta.1-final-campaign.json` within its explicit time and launch limits. A source
change invalidates the frozen candidate and reruns only affected focused checks, one stable
complete headless gate, the rebuilt candidate, and the two-cycle installed smoke. It does not
restart unrelated validation. Any identity, schema, semantic, privacy, security, manifest,
cleanup, or owner-usability failure stops promotion. Do not copy hashes from diagnostics or
historical Slice 5/6 evidence.

During owner cutover, keep the original source and verified backups unchanged. On a failed
post-activation check, stop financial mutations, use the product's verified rollback action, restart
the sidecar, relaunch, verify the restored logical manifest, and record the owner's decision. Never
hand-edit or silently repair financial data.
